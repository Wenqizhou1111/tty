# MyIME 示例词典（UTF-8，无 BOM 也行，带 BOM 也行）
#
# 格式： <码> <词> [权重]
#   码 = 空格分隔的键序列。拼音输入法就是拼音音节（不带声调）；
#        换成五笔/双拼/自定义码表时，把码换成对应的键序列即可，
#        引擎的流程完全一样（见 设计文档.md「引擎怎么换成别的码表」）。
#   词 = 上屏文字（可以是多个字，也可以是英文）
#   权重 = 排序分，越大越靠前；省略按 0 处理
#
# 权重不是「标准词频」，只是演示排序：数字键选字、首候选加粗都靠它。
# 真实项目应该用词频统计表批量生成这个文件。
